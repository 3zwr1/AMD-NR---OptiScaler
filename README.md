# AMDNR 0.3.5.8R1

Mod 0.3.5.8R1 · Launcher 0.3.5.52 · Anywhere host refresh

Use AMDNR-Launcher.exe to manage installation and runtime dependencies. The mod and Anywhere ZIPs are separate package assets: do not extract all ZIPs into a game folder. External runtimes remain separate downloads; no NVIDIA runtime DLLs or NR weight files are included here.

This update covers targeted startup/frame-generation fixes, FSR provider selection, Anywhere runtime choice, Store ReShade eligibility, and the new Anywhere FSR FG path. Read CHANGELOG.md and KNOWN-LIMITS.md before testing. Ghosting is not declared universally fixed.

If a problem remains, reproduce it once and use COLLECT LOGS -> SEND TO AMDNR. Include the game, GPU, runtime/model, interleave setting and a matching crash dump when available.

The local files are assembled and signed; online download-channel activation is a separate step. Until that step, the launcher's online catalog still reflects the existing release.
