# AMDNR 0.3.5.8R1

المود 0.3.5.8R1 واللانشر 0.3.5.52، مع تحديث Anywhere.

استخدم اللانشر لإدارة التثبيت والمكونات. ملف المود وملف Anywhere حزمتان منفصلتان؛ لا تفك كل الملفات داخل مجلد اللعبة. المكونات الخارجية تبقى تنزيلات مستقلة.

يشمل التحديث إصلاحات محددة لبدء التشغيل وتوليد الإطارات واختيار FSR وruntime داخل Anywhere وتثبيت ReShade لألعاب Store. يتضمن مسار FSR FG في Anywhere، لكن اختبار نجاح الاستدعاءات لا يثبت جودة كل إطار معروض.

الـghosting ليس محلولًا بشكل عام، وبعض تقارير الكراش وتأخر interleave والأجهزة المحمولة ما زالت تحتاج تحققًا. راجع CHANGELOG.md وKNOWN-LIMITS.md. أرسل COLLECT LOGS بعد إعادة المشكلة مع اسم اللعبة والكرت والـruntime والموديل والإعدادات.

هذه حزمة محلية؛ تفعيل روابط التحديث على الخادم لم يتم بعد. التوقيعات موجودة مع ختم زمني، لكن تحقق Windows المحلي يرجع UnknownError، وليس Valid.
