1. What this notice covers
--------------------------

The following is AMDNR's own work, Copyright (c) 2026 3zwr1 (AMDNR):

  * every source file, shader and script written for AMDNR;
  * AMDNR's modifications to OptiScaler's files and to the other upstream code
    listed in section 5;
  * the release texts, menus and documentation written for AMDNR.

It covers every AMDNR release from 0.1.0 onward, including 0.3.3, 0.3.4, 0.4.0
and later, as recorded in CHANGELOG.md. Highlights:

  * AMDNR's AMD Neural Rendering pipeline: model interleave (Guided fill and the
    self-tuning interleave), the temporal stability pass, the residual controls
    (strength, limit, edge fade) with the Catmull-Rom resample and its ringing
    bound on the upstream residual resolve, NR resolution above 100% and dynamic
    NR resolution (the 25-100% NR resolution is upstream), the detail/colour and
    sharpen passes, the highlight proxy and its decode by the original, NR style
    presets, the HOME toggle default with its notice and input fix (the
    ToggleKey binding is upstream), the NR capture tool and the Neural tab.
  * The lmxxf runtime inside OptiScaler (0.3.0 and later): AMDNR's integration of
    lmxxf's network into OptiScaler's AMD path, the LmxxfNrRuntime.pak format,
    network history and passes, the edit shaper, auto-exposure, self-healing,
    the Vulkan-bridge warm-up, and the UE5 queue and command-list robustness.
  * The lmxxf RDNA 3 (RX 7000) backend (0.3.3; see AMDNR_RDNA3_BACKEND.txt).
  * The "c32w" one-wave C32 kernels for the lmxxf network on RDNA 4 (0.3.3.2;
    amdnr_c32w_family.hsaco in LmxxfNrRuntime.pak, SHA-256 pinned in
    LmxxfNrRuntime.dll), Copyright (c) 2026 3zwr1 (AMDNR). They run lmxxf's
    network (Kien, MIT; see lmxxf_LICENSE.txt). Acknowledgement: AMD's public
    RDNA 4 WMMA documentation (AMD GPUOpen, the ROCm matrix instruction
    calculator), used for ideas only; no code was taken from it.
  * The integration of RenoDX's colour composition into both AMD runtimes (0.3.3;
    the maths is RenoDX's and the dlssnr.hlsl lineage's - Dagherbou, wilsjo2 - see
    RenoDX_ATTRIBUTION.txt and the CREDITS in amd/NrCompose.h).
  * The FSR Ray Regeneration path-traced profile, the SSS-guided skin smoothing
    and the Ray Regeneration A/B and diagnostic tools (0.3.3).
  * The graphics-state hooks and restore (GraphicsSnapshotHooks.h) on the
    upstream snapshot bookkeeping (GraphicsSnapshot.h); not installed in 0.3.3.
  * The AMDNR Launcher (0.4.0).
